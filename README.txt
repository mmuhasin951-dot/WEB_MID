FILES
- index.html: page structure and game screens
- style.css: responsive visual design
- script.js: gameplay, keyboard input, scoring, timers and results

HOW TO RUN
1. Extract the ZIP file.
2. Open index.html in Google Chrome, Edge, or Firefox.
3. Select a difficulty and choose Bubbles or KeyMagnet.
4. Press Start Game / Start Training and use your physical keyboard.

GAME RULES
MODE A — BUBBLES
- Match a visible bubble letter by pressing the same keyboard key.
- Correct match: +10 points.
- Incorrect key: -2 points (score cannot go below zero).
- A bubble that reaches the upper arena boundary counts as a miss.
- Six misses end the session.
- The game has a countdown timer. Bubbles move and spawn at a faster rate at higher difficulties.

MODE B — KEYMAGNET
- Press the highlighted target letter using the physical keyboard.
- Correct response: +10 points.
- Incorrect response: -3 points (score cannot go below zero).
- The game ends when the selected difficulty's correct-target goal is reached.
- Correct, incorrect, elapsed time, and average response time are shown.
- Choose Home row, Top row, or Mixed practice set before starting.

DIFFICULTY
- Easy: slower bubbles / 60-second timer / 12 correct targets.
- Medium: standard speed / 45-second timer / 18 correct targets.
- Hard: faster bubbles / 35-second timer / 25 correct targets.

CONTROLS
- Restart: starts a fresh session of the current mode.
- Reset: clears current progress and returns to the ready state.
- Home: returns to mode selection.
- No page reload is used by these controls.
